Support

Bala Print se connecte à votre propre serveur Bambuddy (logiciel libre, auto-hébergé) pour suivre et piloter vos imprimantes 3D Bambu Lab.

Contacter le développeur Depuis l'App Store : page de l'app › « Assistance de l'app ».

Connexion au serveur

  • Saisissez l'adresse complète avec le port, par exemple http://192.168.1.10:8000.
  • Si l'authentification est activée sur Bambuddy, utilisez une clé API (Bambuddy › Réglages › Clés API) ou vos identifiants. La double authentification n'est pas prise en charge : utilisez une clé API.
  • Pour un serveur en HTTPS avec un certificat auto-signé, activez « Accepter un certificat non vérifié » dans la fiche du serveur.
  • Un serveur exposé uniquement via l'interface intégrée de Home Assistant (Ingress) n'est pas joignable : exposez le port de Bambuddy.

Sans serveur

Touchez « Essayer la démo » au premier lancement pour découvrir toutes les fonctions avec des imprimantes fictives.

Bala Print est une application indépendante, non affiliée à Bambu Lab ni au projet Bambuddy.

Politique de confidentialité

Dernière mise à jour : 28 octobre 2026. Éditeur : Julien Lamadon.

Données collectées

Bala Print ne collecte aucune donnée personnelle. L'app ne contient ni compte utilisateur, ni publicité, ni outil de mesure d'audience, ni service tiers de suivi.

Données stockées sur votre appareil

  • Les serveurs que vous ajoutez : nom, adresse, et selon votre choix une clé API ou un jeton de session. Votre mot de passe n'est jamais conservé.
  • Vos préférences d'affichage et un résumé de l'état des imprimantes, partagés avec les widgets et l'Activité en direct de l'app.

Ces données restent sur votre appareil et sont supprimées avec l'app.

Communications réseau

L'app communique uniquement avec les serveurs Bambuddy que vous avez configurés. Aucune donnée n'est envoyée au développeur.

Analyses intelligentes

Les analyses des statistiques sont calculées sur l'appareil, avec Apple Intelligence lorsqu'il est disponible. Rien n'est envoyé sur Internet pour ces analyses.

Enfants

L'app ne collecte aucune donnée, y compris auprès des enfants.

Contact

Pour toute question : page de l'app sur l'App Store › « Assistance de l'app ».

Privacy Policy

Last updated: October 28, 2026. Publisher: Julien Lamadon.

No data collected. Bala Print collects no personal data. There are no user accounts, ads, analytics or third-party tracking.

Stored on your device. The servers you add (name, address, and either an API key or a session token; your password is never stored), your display preferences, and a summary of printer status shared with the app's widgets and Live Activity. This data stays on your device and is deleted with the app.

Network. The app only talks to the Bambuddy servers you configure. Nothing is sent to the developer.

Insights. Statistics insights are computed on device, using Apple Intelligence when available.

Support. Bala Print connects to your self-hosted Bambuddy server. Enter the full address with its port (for example http://192.168.1.10:8000), use an API key when authentication is enabled, or try the built-in demo without a server. Contact the developer from the app's App Store page › "App Support".
